# WIM — World Is Mine

# WIM (World Is Mine) est un projet réalisé dans le cadre de ma formation de Développeur Web.

# Développé entièrement seul, WIM est une plateforme de création, organisation et partage d'albums photos, pensée autour d'une dimension sociale bienveillante.

# WIM met l'accent sur la qualité et la mise en valeur des albums, afin de permettre à chacun de revivre ses plus beaux moments à travers ses photos

# Le site permet notamment de :

# créer des albums photos ;

# partager ses albums avec d'autres utilisateurs ;

# créer des albums collaboratifs à plusieurs ;

# interagir avec une communauté dans un environnement positif et respectueux (no-chat).

# Ce projet me permet de mettre en pratique l'ensemble des compétences acquises durant ma formation : conception, UX/UI, développement Front-End et Back-End, PHP orienté objet, base de données, UML, sécurité, tests et déploiement.
